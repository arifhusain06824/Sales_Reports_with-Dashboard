**# 📊 Sales Reports Analysis - Excel Project

An end-to-end Excel Data Analysis project on a retail sales dataset containing 1500 orders across 5 regions.

## 🎯 Project Objective
To analyze sales performance, identify top-performing products, regions, and salespersons, and provide actionable business insights using Excel.

## 🛠️ Tools & Techniques Used
- **Microsoft Excel** (Pivot Tables, Charts, Slicers, Conditional Formatting)
- **Data Cleaning** (Handling missing values, removing duplicates)
- **KPI Analysis**
- **Pivot Reports & Dashboard**

## 📁 Dataset Overview
- **Total Records:** 1500 orders
- **Time Period:** Jan 2023 – Jun 2025
- **Regions:** East, West, North, South, Central
- **Products:** Laptop, Phone, Desk, Chair, Monitor, Printer, Tablet

## 📈 Key Performance Indicators (KPIs)
| KPI | Value |
|-----|-------|
| Total Sales | ₹43,79,992 |
| Total Quantity | 15,616 |
| Total Orders | 1,500 |
| Average Order Value | ₹2,920 |
| Total Customers | 1,371 |
| Total Shipping Cost | ₹41,261 |
| Returned Orders | 372 |

## 🔍 Key Insights
- **North region** has the highest sales (₹9.68 Lakhs)
- **Store D** is the top-performing store (₹12.05 Lakhs)
- **Bob** is the top salesperson (₹7.97 Lakhs)
- **FREESHIP promotion** generated the highest revenue
- **Tablet & Laptop** are the top-selling products
